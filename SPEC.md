# Simple Cut — basic CapCut-like iPhone app for Rob

Goal: basic, not bloated. No account, no ads, no templates, no AI junk.
Build path (proven Nov 22, 2026 for TPP app): SwiftUI + AVFoundation, GitHub Actions Mac runner builds unsigned .ipa, Rob sideloads with iloader. No Mac needed. GitHub account: trailerparkproductions.

## V1 features (Rob confirmed / asked)
- Pick videos AND photos from Photos (asked Nov 25, 2026: "Can it add photos to")
- Photos act like short clips: choose how long each photo shows (e.g. 2 / 3 / 5 seconds)
- Mix photos and videos in one timeline, drag to reorder
- Trim each video clip (start / end sliders)
- Add big text on a clip/photo
- Add music file
- Export / save to Photos

## Not in V1 (keep it light)
- No templates, filters pack, stickers, AI captions, cloud account
