# Simple Cut — basic video editor for Rob (sideload .ipa)

Basic CapCut-like editor. No account, no ads, no templates.

Pick videos and photos, trim, reorder, add text, add music, save to Photos.
Photos show for a time you pick (2 / 3 / 5 / 8 seconds).

Built the same way as the TPP app (Nov 22, 2026): GitHub Actions Mac
runner builds an unsigned .ipa, Rob sideloads with iloader.
